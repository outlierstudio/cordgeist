# Changelog

## 0.1.0

- Single-phone Linux USB AOA HID CLI/daemon and official rmcp local stdio.
- Private per-session MCP ownership, exclusive leases, original-identity recovery
  and truthful sent/partial/unknown receipts; post-action capture opt-in.
- Generic daemon geometry, optional calibration, native-size screenshots,
  bounded element collection and explicit screenshot fallback.
- Server-computed element-reference taps; daemon-owned common-name app resolution.
- Honest availability after clean hand-back, with explicit cleanup/failure reasons.
- Explicit ADB app launch and BACK/HOME/ENTER; touch/ASCII remain HID.
- Portable native bundle, explicit scoped udev instructions and license/source material.
- Note 9 portrait evidence only. No Bluetooth HID, OCR, streaming or media MCP.
